# Feature map

One file per user-facing surface. Each names sub-features, how to reach it
as a user, how to drive it during verification, and gotchas.

- [login](login.md) — Spotify PKCE connect, session restore, logout.
- [player](player.md) — now playing, transport, seek, volume, devices, episodes, throttle parking.
- [queue](queue.md) — upcoming rows, virtualized list, Enter-to-play, context, capped/queued states.
- [browse](browse.md) — search recents + paging, playlist/artist/episode detail, truthful walls.
- [lyrics](lyrics.md) — synced highlight, click-to-seek, offset, words, translation, romaji, cache.
- [layout](layout.md) — edit lock, drag, magnet snap, resize, preview/undo, dock, coach pill.
- [settings](settings.md) — tray, appearance (theme/density/surface/corners/preset/scale), visibility, autostart, reset.
- [shortcuts](shortcuts.md) — remappable global + focused chords, keyboard geometry, show/hide.
- [updater](updater.md) — version row, check/install/restart, release feed.
- [liquid-glass](liquid-glass.md) — solid default, glass/sharp opt-ins, light contrast, no lens.
- [theme-surface](theme-surface.md) — 2.5.4 map: theme lanes + surface/corners drivers, pastel×glass hook.
- [settings-color](settings-color.md) — 2.5.4 map: accent color-picker hooks (not landed; assert nothing yet).
- [mini-marquee-volume](mini-marquee-volume.md) — 2.5.4 map: mini gate, collapse, title marquee, volume parity.
- [web-harness](web-harness.md) — mocked UI runs, live shape checks, token rules.
